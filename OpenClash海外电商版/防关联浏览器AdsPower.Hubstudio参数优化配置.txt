防关联浏览器（如 AdsPower、Hubstudio）是多账号运营的最后一道防线。配合前面在 OpenClash 中搭建的独享住宅 IP 链式代理，需要针对防关联浏览器进行以下深度优化配置，以确保**软路由层**与**浏览器环境层**无缝对齐：

---

### 一、 网络与代理连接设置（关键第一步）

在防关联浏览器创建环境时，网络连接方式有两种填法，取决于您的具体需求：

#### 方案 A：使用 OpenClash 本地 Socks5 端口（推荐，直接利用链式代理）

不需要在浏览器中填写额外的代理账号密码，直接指向上游软路由的代理服务：

* **代理类型**：`Socks5` 或 `HTTP`
* **代理主机 (Host)**：`192.168.11.1`（即 OpenWrt 路由器 TikTok_LAN 接口的 IP）
* **代理端口 (Port)**：`7890` (HTTP) 或 `7891` (Socks5) / `7893` (Mixed)
* **原理**：浏览器把所有流量扔给 OpenClash，OpenClash 根据 `192.168.11.X` 的源 IP 规则自动命中`纯静态住宅-落地组`。

#### 方案 B：直连模式（仅依赖 OpenClash TUN 模式）

* **代理类型**：`不使用代理 / 直连 (Direct)`
* **前提**：电脑已连接 `TikTok_Work_WiFi` 或处于 `192.168.11.X` 网段，且 OpenClash 开启了 **TUN 模式**。
* **原理**：TUN 模式接管了电脑网卡的系统级流量，浏览器直连也会被硬劫持并分流到住宅 IP 出口。

### 二、 防关联浏览器核心指纹与参数优化

进入 AdsPower / Hubstudio 的环境高级配置面板，按下表进行参数精细化对齐：

| 配置项 | 推荐设置 | 优化说明与原因 |
| --- | --- | --- |
| **WebRTC** | **替换 (Replace) / 禁用 (Disable)** | **极度重要**。设为“替换”会使用当前代理 IP 替换真实 IP；若选“禁用”能 100% 杜绝 UDP 泄露。配合 OpenClash 的 `UDP 3478 REJECT` 规则实现双重保险。

 |
| **地理位置 (Geolocation)** | **询问 (Prompt) 或 自动匹配 IP** | 勾选“根据 IP 自动填充经纬度”。严禁允许浏览器直接获取 PC 硬件的真实 GPS 位置。 |
| **时区 (Timezone)** | **基于 IP 自动匹配** | 勾选“基于 IP 自动匹配时区”。如果住宅 IP 在洛杉矶，环境会自动切换为 `America/Los_Angeles (GMT-7/GMT-8)`，避免出现“IP 在美国，时区在东八区”的风控特征。 |
| **语言 (Language)** | **基于 IP 自动匹配** | 勾选“基于 IP 自动匹配语言”或手动指定为 `en-US`（根据目标国选择）。 |
| **DNS 优化** | **跟随系统 / 使用代理 DNS** | 关闭浏览器自定义的 DoH (DNS-over-HTTPS) 功能，强制让 DNS 解析走 OpenClash 的 Fake-IP 机制，防止 DNS 测漏。 |
| **User-Agent (UA)** | **匹配真实内核的版本** | 不要盲目选择最新的操作系统或过于偏门的老旧 UA。AdsPower/Hubstudio 会自动匹配对应的内核版本（如 Chrome 120+）。 |
| **Canvas / WebGL** | **噪音 (Noise) / 隐匿** | 开启硬件指纹混淆，使每次生成的浏览器环境 HTML5 绘图指纹唯一且不可关联。 |
| **Client Hints** | **开启/自动匹配** | 确保与设置的 User-Agent 匹配，防止平台通过 `Sec-CH-UA` 属性检测出 UA 伪造。 |

### 三、 环境搭建完成后的测漏验证流程

在防关联浏览器中打开新建的环境，依次访问以下三个专业测试网站，确保环境无缝防关联：

1. **IP 与代理检测：[ipinfo.io**](https://ipinfo.io)
* **查看重点**：`type` 是否为 **isp** 或 **hosting/residential**；`country` 是否为目标国。


2. **综合伪装度检测：[whoer.net**](https://whoer.net)
* **查看重点**：伪装度得分必须达到 **90% - 100%**。如果扣分，根据页面提示检查是时区不匹配、语言不匹配还是系统时间问题。


3. **WebRTC 专项测试：[browserleaks.com/webrtc**](https://browserleaks.com/webrtc)
* **查看重点**：检查 `Public IP Address` 和 `Local IP Address` 是否**只显示住宅 IP** 或**显示为 Disabled / N/A**。如果出现 192.168.X.X 或国内真实公网 IP，说明 WebRTC 泄露，需立即检查 OpenClash 的规则是否生效。

### 四、 运营团队多账号操作小贴士

1. **一号一环境**：AdsPower / Hubstudio 中一个环境只绑定一个 TikTok / Claude / FB 账号，且固定使用同一个住宅 IP 服务。
2. **环境隔离同步**：如果团队多人协同，请直接在防关联浏览器中分享环境（Share Profile），不要在多台电脑上分别新建环境登录同一个账号。
3. **Cookie 导入导出**：首次登录账号后，建议导出 Cookie 备份。以后若遇到网络波动或换设备，导入 Cookie 可大幅降低被要求验证码或封号的风险。
